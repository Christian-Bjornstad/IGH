NOTES

Packages are installed in .python_felles_packages in the project folder. Write
access to the central Python installation is therefore not required.

The app uses Windows' managed certificate store when contacting IMGT
and ARResT. Certificate validation is active. If a certificate error still
appears after a new installation, IT must check the organization's proxy-/Ivanti-
root certificate in Windows Trusted Root Certification Authorities.

If the job network does not have access to PyPI, IT or a development PC can place
Windows/Python 3.14-compatible wheel files in a folder called wheelhouse in
the project folder. The installation script uses this automatically without network access.

Regular BAT file or Windows shortcut is not used. Python Common opens first,
and then the command is pasted in.
