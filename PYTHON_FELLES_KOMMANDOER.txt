IGH Merge - Install & Run (Python FELLES)
========================================

Denne appen bruker det delte Python FELLES-miljøet som er tilgjengelig
via Ivanti PowerGate paa jobb-PC.

Rask start (etter install)
--------------------------
1. Dobbeltklikk ``START_IGH_MERGE.cmd`` paa skrivebordet.
   Filen bruker bare vanlig cmd og Windows-programmet ``clip.exe``.
   PowerShell eller hjelpefiler med .ps1 brukes ikke.

Installasjon (forste gang, eller etter Python FELLES-oppgradering)
-----------------------------------------------------------------
1. Dobbeltklikk ``INSTALL_IGH_MERGE.cmd``.
   - Skriptet kjoeres som din innloggede bruker via Ivanti PowerGate.
   - Naavaerende Python FELLES-versjon logges til
     ``%LOCALAPPDATA%\IGH\logs\install.log``.
2. Installasjonen er idempotent - kjoer gjerne paa nytt etter en
   Python FELLES-oppdatering for aa faa en ren versjon.

Hva installasjonen gjoer
------------------------
- Bruker Python FELLES sin innebygde pip-funksjon, samme moenster som MolStat.
- Installerer prosjektet redigerbart i brukerens egne site-packages fra
  ``pyproject.toml``. Dette inkluderer openpyxl, PyQt6, reportlab, requests,
  truststore, python-docx og websocket-client.
- Skriver aldri til ``requirements.txt``. De fem pinnede linjene beholdes
  uendret for kompatibilitet med andre Python FELLES-kjoeringer.

Hva start-skriptet gjoer
------------------------
- Setter ``PYTHONPATH`` til prosjektmappa slik at
  ``python -m igh_merge`` finner kildekoden uten aa installere pakken.
- Kjoerer ``python -m igh_merge`` - samme inngang som PyInstaller bygger.

Kjoere direkte uten cmd-filene
------------------------------
For utvikling i en vanlig terminal (PowerShell / bash) er begge skriptene
ogsaa kjoertbare direkte:

    python install_python_felles.py
    python start_python_felles.py

CLI-modus
---------
Skriv ut en helper-tekst:

    python -m igh_merge --help

Loggfiler
---------
- Installasjon: ``%LOCALAPPDATA%\IGH\logs\install.log``
- Start:        ``%LOCALAPPDATA%\IGH\logs\start.log``
